How the visual-plan skill works

It turns a task into a plan you can look at — and answer — before any code is written.

01The old way vs one visual pass

04Anatomy of a decision card

This is a real card from the CSV-export plan. Click an option. Notice the recommended default and the "Other" escape hatch.

Very large reports could outrun the 30-second timeout. How do we handle them?

Most reports are small and stream in under a second. A few have tens of thousands of rows. rows_to_csv() could hold the request open past the gateway timeout.

Stream now, cap at 50,000 rowsrecommendedAbove the cap, ask the user to narrow filters. No queue or worker is built. The seam to go async stays open.
Background job + emailed linkRobust for any size, but adds a queue, a worker, storage, and email — none of which exist yet.
OtherNone of these fit — type what to do instead.

Selected: Stream now, cap at 50,000 rows (the default)

  • Recommended default. The AI's answer is pre-selected. Agree by doing nothing.
  • Plain question. It asks the practical choice, not the mechanism.
  • Grounded. It names the real function, rows_to_csv(), from your code.
  • Other. Every card ends with a free-text escape hatch.
  • Copy decisions. In the real plan, one button copies every answer back to chat.

06Words worth knowing

decision card
A multiple-choice question in the plan. It has a recommended default and an "Other" field. You answer it in the browser.
intent gap
A point where the task does not say what the result should do. The AI asks about it instead of guessing the defensive reading.
custom instructions
An optional file that sets what a finished plan must contain for your team, plus where to record it.
compact plan
The short markdown the agent records on approval. The HTML file stays the human-readable reference.
deliberately not built
A note in the plan: what was cut, the seam that keeps it pluggable, and the signal that would revive it.
challenge-plan
A separate skill. A different model attacks the plan for over-building. It may only cut, reuse, simplify, or ask.

07Worth knowing

One self-contained file

No CDN, no build step. The plan opens straight from disk, offline.

Grounded in real code

The diagram names real functions and files. The AI reads the code first, not just the ticket.

Tracker-agnostic

Linear, Jira, GitHub Issues, a file, or nothing. The skill does not assume one.

Copy that never fails

"Copy decisions" falls back from the Clipboard API to a manual box, so it works inside a sandboxed preview.
